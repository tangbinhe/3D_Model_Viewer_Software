本地 API 调用与参数文档
基础地址 · 仅本机访问 http://127.0.0.1:8765

先在播放器中手动载入模型，再发送指令。服务不开放给局域网或公网。

1. 接口列表
GET /api/health

检查本地 HTTP 服务是否存活，成功返回 {"ok":true}。

GET /api/status

查询模型、表情、动作库、当前背景、视角、界面状态和最近指令结果。

POST /api/command

提交表情、动作、背景、视角和纯净模式指令；请求体必须是 JSON 对象。

POST /api/status

内部接口：播放器向本地服务上报状态，外部程序请使用 GET 查询。

GET /api/commands/poll

内部接口，外部不要调用。读取会同时清空待执行队列，外部调用会抢走等待播放器执行的指令。

2. POST /api/command 参数

请求头使用 Content-Type: application/json。所有参数都可组合，但至少包含 expression、action、background、view、clean、danmaku、danmakuVisible 之一。

参数类型 / 默认取值与作用
expression字符串
缺省不修改		VRM 表情名。"" 或 neutral 恢复无表情。
weight数字
默认 1		表情强度，范围 0–1。只辅助 expression，不能单独发送。
action字符串
缺省不修改		基础动作名或动作库 ID；stop 停止当前动作。
duration数字
默认 2 秒		范围 0.2–30，只控制基础动作，不能单独发送；动作库 VRMA 使用自身时长。
background字符串
缺省不修改		纯色背景，仅支持 #RRGGBB，例如 #00FF00。
view字符串
缺省不修改		固定视角：front、right、left、back、top、perspective、fit。
clean布尔值
缺省不修改		true 隐藏控制界面，false 恢复界面。
danmaku字符串
缺省不新增		发送 1–200 个字符的弹幕并显示窗口；自动去除首尾空白。
danmakuVisible布尔值
缺省不修改		true 添加弹幕窗口，false 隐藏窗口但保留消息。

同一次调用的执行顺序：背景 → 视角 → 控制界面 → 弹幕内容 → 弹幕窗口 → 表情 → 动作。weight 和 duration 不能作为唯一参数；未知字段或格式错误返回 HTTP 400。

4. 基础动作与角色动作库

基础动作

idlenodwavebowspinstop

依次为待机、点头、挥手、鞠躬、旋转、停止。idle 持续循环；nod、wave、bow、spin 使用 duration，结束后停止。

角色动作库

当前内置 132 项：14 个 motion 动画循环播放，118 个 pose 姿势播放一次后定格保持。action 直接传动作 ID，不要传文件路径。

pixiv-fit-02fit-vroid86-03fit-sf-04

动作库不受 duration 控制。发送 {"action":"stop"} 可停止动画或取消姿势保持。

查询全部动作 ID、中文名称、分组和类型：

curl -s http://127.0.0.1:8765/api/status | python3 -c 'import json,sys; [print(m["id"], m["kind"], m["group"], m["name"]) for m in json.load(sys.stdin)["motions"]]'
5. 背景、视角与纯净模式

背景

background 只接受六位 HEX 纯色，格式为 #RRGGBB。不支持颜色名、三位 HEX、RGB 数组或图片路径；背景图片请在播放器界面手动选择。

#00FF00#FFFFFF#0B1020

视角

frontrightleftbacktopperspectivefit

依次为正面、右侧、左侧、背面、顶部、3D 透视、适配。clean 为 true 时隐藏界面，直播采集后可用 false 恢复。

6. 组合调用示例

同时设置 80% 开心表情、角色动作、绿幕、正面视角，并隐藏控制界面：

curl -X POST http://127.0.0.1:8765/api/command \
  -H 'Content-Type: application/json' \
  -d '{
    "expression": "happy",
    "weight": 0.8,
    "action": "pixiv-fit-02",
    "background": "#00FF00",
    "view": "front",
    "clean": true
  }'

停止动作、清除表情并恢复控制界面：

curl -X POST http://127.0.0.1:8765/api/command \
  -H 'Content-Type: application/json' \
  -d '{"expression":"neutral","action":"stop","clean":false}'
7. 状态、返回码与错误处理

POST /api/command 返回 HTTP 202 只表示指令已进入播放器队列，不代表模型已成功执行。随后查询 GET /api/status，检查 lastCommand.ok；失败时查看 lastCommand.error。

curl -s http://127.0.0.1:8765/api/status | python3 -m json.tool

lastCommand 还包含原始 command 和执行时间 at。不存在的表情或动作可能先返回 202，再由 lastCommand 报告错误；JSON、字段、类型或范围校验失败会直接返回 400，队列已满返回 429。

GET /api/status 主要字段

ready播放器状态上报是否就绪 model / format / vrm当前模型名、格式及是否为 VRM expressions当前模型实际可用的表情名 animations模型文件内嵌动画片段 motions动作库 ID、名称、分组和 kind action / actionName当前动作 ID 和名称，无动作为 null background / view / clean当前背景、视角和界面隐藏状态 danmakuVisible弹幕窗口当前是否显示 danmakuMessages最近 50 条弹幕内容及发送时间 lastCommand最近一条指令的实际执行结果
8. 弹幕互动 API

右侧“弹幕互动”区域可添加或隐藏浮窗，拖动浮窗标题栏可调整位置。API 发送弹幕不会重置已拖动的位置。

发送文字并显示窗口：

curl -X POST http://127.0.0.1:8765/api/command \
  -H 'Content-Type: application/json' \
  -d '{"danmaku":"大家好，欢迎来到直播间！","danmakuVisible":true}'

danmaku 可单独使用，会自动显示窗口；同一次调用同时设置 danmakuVisible 为 false 时，消息仍保留但窗口隐藏。隐藏不会清空历史，最多保留最近 50 条。

curl -X POST http://127.0.0.1:8765/api/command \
  -H 'Content-Type: application/json' \
  -d '{"danmakuVisible":false}'
9. 使用限制
  • 启动后保持空白，必须先在界面手动打开 FBX、GLB 或 VRM 模型。
  • API 不能通过文件路径打开模型，也不能上传模型。
  • API 只能设置纯色背景，不能设置背景图片。
  • 表情和骨骼动作需要绑定完成的 VRM；静态模型不能使用这些能力。
  • 其他模型的表情以 expressions 为准；全部动作以 motions 为准。
